Projetos

AcademicFlow-Agent

Problema: Coordenar tarefas e registrar decisões em reuniões acadêmicas costuma ser um processo manual e desorganizado.

Solução: Desenvolvi um agente com LangGraph e ReAct que entende pedidos em linguagem natural, aciona ferramentas sozinho e organiza o planejamento usando modelo local (Ollama / Llama 3.2).

  • Python
  • LangGraph
  • LangChain
  • Ollama (Llama 3.2)
  • Pytest

SlopeMonitor — HackaTruck

Problema: Encostas em áreas de risco precisam de monitoramento contínuo para prevenção de acidentes e deslizamentos.

Solução: Desenvolvi em equipe no HackaTruck um sistema IoT com sensores em Arduino, integração no Node-RED e um app iOS em SwiftUI com mapa para visualização e alertas em tempo real.

  • SwiftUI
  • MapKit (iOS)
  • C++ (Arduino)
  • Node-RED
  • IoT

JavaEventPlanner

Problema: Gerenciar compromissos e agendas com regras de repetição e categorias diferentes sem deixar o código acoplado.

Solução: Desenvolvi um app desktop em Java Swing no padrão MVC, aplicando orientação a objetos com herança e polimorfismo para separar as regras de negócio e salvar os dados localmente.

  • Java 17+
  • Swing GUI
  • Padrão MVC
  • POO
  • File I/O
