Projetos

AcademicFlow-Agent

Agente autônomo baseado no padrão ReAct (Reason + Act) com LangGraph. Interpreta intenções em linguagem natural, executa chamadas dinâmicas a ferramentas (Tool Calling) e persiste o estado do planejamento usando LLM local (Ollama / Llama 3.2).

  • Python
  • LangGraph
  • LangChain
  • Ollama (Llama 3.2)
  • Pytest

SlopeMonitor — HackaTruck

Sistema IoT distribuído desenvolvido no programa HackaTruck (Apple/IBM) para monitoramento de encostas em tempo real. Integra sensores em C++/Arduino, gateway em Node-RED e app iOS em SwiftUI com MapKit para alertas.

  • SwiftUI
  • MapKit (iOS)
  • C++ (Arduino)
  • Node-RED
  • IoT

JavaEventPlanner

Aplicação desktop estruturada no padrão MVC para gerenciamento de eventos com regras de recorrência e categorização. Implementa herança, polimorfismo, interface gráfica com Java Swing e persistência em arquivo local.

  • Java 17+
  • Swing GUI
  • Padrão MVC
  • POO
  • File I/O
